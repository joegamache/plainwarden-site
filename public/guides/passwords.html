Use a password manager and unique passwords

Give every account its own long password, stored in a business password manager.

Why it matters

When one site is breached, attackers try the same password everywhere else. Unique passwords stop that. Current NIST guidance favors long passwords and checking against known-breached passwords over forced periodic changes.

Steps

  1. Choose a business password manager with two-step login and shared vaults for the firm.
  2. Have each person create a long master password (a passphrase of four or more random words works well) and turn on two-step login for it.
  3. Move every work password into the manager and replace reused or short ones with generated passwords.
  4. Share firm accounts through the manager's shared vault, not by email or sticky note. Better still, give each person their own login.
  5. Change a password right away if it may have been exposed. You don't need to change strong, unique passwords on a schedule.
  6. When someone leaves, remove them from the password manager and change any shared passwords they knew.

You're done when

  • Everyone uses the password manager.
  • No password is reused across work accounts.

References: NIST SP 800-63B; IRS Publication 4557
